# ADR-002：自研编排链路

> 文件名：`ADR-002-自研编排链路.md`
> 类型：adr
> 状态：已接受
> 读者：任何想知道"为什么这么选"的人（含 AI）
> 结论：全链路编排（语音识别→对话大脑→语音合成→口型→渲染）自研实现，不基于开源整包二次开发

## 背景

开源社区已有数字人整包方案（如 Linly Talker 等，集成多模型、功能丰富），可直接部署使用。但整包方案存在：链路逻辑黑盒（内部编排不可控）、模型绑定（难以替换单个环节）、同质化（大量项目基于同一整包，难以讲清个人贡献）。

## 决策

我们将**自研全链路编排**：FastAPI 网关 + 会话状态机（听→想→说→演），各环节模型通过统一抽象接入，每一行链路代码可控、可解释、可替换。开源整包仅作为架构参考与对照验证，不进入主链路。

## 被否方案

| 方案 | 否掉原因 |
|---|---|
| 开源整包二次开发（Linly Talker 类） | 链路黑盒不可控；模型绑定难替换；同质化，无法讲清个人贡献 |
| 端到端模型（研究前沿路线） | 实时性与效果未达工程可用；属研究范畴 |

## 后果

- 正面：全链路可控可观测可调试；每个环节可独立替换（如切换语音合成方案）；面试/评审可讲清每一行
- 负面：工作量高于整包方案；需要自行处理各模型间的接口适配与异常
- 中性：与"模型开源 + 编排自研"的整体原则一致
