### 一、CSS 死规则清理与幽灵选择器修复

- [x] 用「CSS 定义类 vs tsx/ts/html 引用类」的比对定位孤儿类：`edu.css` 定义 176 个 `.edu-*`，其中 **35 个零引用**
- [x] 剔除动态拼接的假阳性：`edu-badge--${state}`、`edu-finding--${kind}` 这类前缀不能按字面量判定（否则会误删 `edu-badge--ok/warn/fail/pending` 与 `edu-finding--ok/info`）
- [x] 删除 46 个规则块（含声明体与紧邻区段注释）：`.edu-pro-*`（Pro 卡片）、`.edu-tool*`（学习工具 4 格）、`.edu-task*`/`.edu-tasks`（今日学习任务）、`.edu-weak*`（待加强知识点）、`.edu-stage-*`（阶段目标图表）、`.edu-advice*`（智能建议）、`.edu-timer*`/`.edu-pomo`（计时器）、`.edu-weekly*`/`.edu-fraction`/`.edu-mastery-row`（本周目标）
- [x] **修复幽灵选择器**：统一点击反馈的 `:where(...)` 列表里写着 `.edu-hist-item`，而侧栏真实类名是 `.edu-history`——该选择器**从未匹配过任何元素**（侧栏「最近对话」链接一直没有统一过渡与按下反馈）。改为 `.edu-history a` 后实测 `transitionDuration = 0.12s`（修复前为 `0s`）
- [x] 选择器列表里的死类做**中性剔除**而非整行删：`.edu-card .edu-weekly-foot, .edu-card .edu-task-foot, ... .edu-card--tasks .edu-start-btn` 只保留仍然活跃的最后一段
- [x] 证据：`edu.css` **46128 → 40930 字节（-11.3%）、2195 → 1821 行（-374 行）**；括号平衡 253/253；无空选择器段、无悬空逗号；CSSOM 枚举确认活跃类规则一个不少（抽检 23 个代表类）、死类一个不剩（抽检 35 个）

## 阻塞与未完成

- **音画时差与口型首帧仍是"待测"**：本轮只做样式与台账结构，没碰链路。要结清这两项需要真实麦克风 + 云 GPU 开机，且音画时差本身需要人工标注的视频（`verify_sync_measure.py` 的工具自校准已通过，缺的是真实链路的数）
- **`.edu-kpi` 等类没有强视觉特征可抽检**：注入式抽检只能核对"该属性非默认"，无法判断"视觉上是否好看"。像素级回归（截图 diff）没有做，属可选的下一步
- **剩余 9 个"孤儿"类中有 6 个是动态拼接的假阳性**（`edu-badge--*`、`edu-finding--*`），脚本已按前缀放过；若将来这些状态真的不再使用，需要先把动态拼接代码删掉才能被脚本发现
- `frontend/src/styles/edu.css` 仍有 40.9KB，尚未按页面拆分（`app.css`/`edu.css` 两套命名空间并存也是历史遗留）——本轮按最小改动原则不动
