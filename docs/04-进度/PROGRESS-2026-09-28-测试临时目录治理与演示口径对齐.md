## 已完成（MUST）

### 一、口型编码器的临时目录治理（可跑性）

- [x] `backend/deploy/lip_encode.py` 支持 `LIP_TMPDIR` 覆盖临时目录根，且**优先复用其下的固定工作目录**（`<prefix>work`），仅在无固定目录时退回 `mkdtemp`
- [x] 动机有实测依据，不是假想兼容：受限运行时（沙箱化）会**拒绝随机后缀目录**的写入，实测同一父目录下 `lipenc_<随机>` 写入失败而 `fresh-fixed` 成功——所以固定目录优先不是绕路，是唯一可行路径
- [x] `backend/eval/fake_lip_server.py` 的进程内截断走同一约定（`LIP_TMPDIR` + `fakesegwork`），消除同类隐患
- [x] 清理阶段失败不再污染业务结果：临时目录退出时的 `chmod`/`rmtree` 被拒时按卫生问题处理（`ignore_cleanup_errors`），不把**一次成功的编码**变成异常
- [x] 新增 `backend/tests/conftest.py`：把 `LIP_TMPDIR` 指到仓库内 `backend/.tmp-lip/`（已 gitignore），pytest 启动即建好固定工作目录，session 结束清空内容
- [x] 证据：`backend/.venv/Scripts/python.exe -m pytest backend/tests -q` → **76 passed**（本轮前为 `5 failed, 71 passed`，5 项失败全部来自系统 temp 被拒，与代码逻辑无关）；跑完 `backend/.tmp-lip/` 下工作目录为空，无残留产物
