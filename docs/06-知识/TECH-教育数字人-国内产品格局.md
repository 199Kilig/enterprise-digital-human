## 1. 触发场景（HUMAN）

做前端重构时，需要回答一个前置问题：**一个"看起来像数字人产品"的界面到底该有什么？**
只读竞品架构文字会被抓包（设计建议必须有可查证依据），所以本轮真去搜了国内教育方向与数字人方向的产品，
覆盖：Khanmigo（美）、Duolingo Max、洋葱学园智能学伴、松鼠Ai（MCM+知识图谱）、清华 OpenMAIC、
腾讯云数智人、HeyGen、Synthesia、九马、百度曦灵、duix 等。

下面这份是国内**教育方向**数字人产品的调研结果（厂商/技术路线/落地形态），
用来回答两个面试常被追问的问题：**这个赛道有多大？你做的事和谁像、和谁不像？**

## 2. 技术要点（MUST）

**产品与技术路线（6 家）**

| 厂商 | 核心定位 | 数字人能力侧重 | 教育场景深度 | 典型落地形态 |
|---|---|---|---|---|
| 与爱为舞（爱学AI） | 教学智能体「大脑+身体」 | 分钟级生成、3DGS 高拟真 | 深度嵌入教学决策 | 数字人导师、AI 分身 |
| 海亮科技 | 场景驱动教育 AI | 早读带读、语音评测 | 单一场景深耕 | 数字人助教「星乐读」 |
| 科大讯飞 | 通用数字人平台 | 实时生成、多模态交互 | 培训/陪练延伸 | 培训数字人、陪练数字人 |
| 世优科技 | 历史人物 IP 数字化 | 高拟真建模、知识库构建 | 文化传承场景 | 一体机部署 |
| 木愚科技 | AI 课程生成系统 | 数字教师分身、肢体语言 | 课程制作与实训 | 超写实数字教师 |
| 蝉镜 | 轻量视频工具 | 文案转视频 | 微课制作 | 虚拟学习伙伴 |

**关键技术事实（可核）**

- **与爱为舞**：自研 **AnyAvatar** 算法，突破传统 3D 数字人对专业标定设备的依赖，降低采集与制作门槛；
  自研 **MoGaFace** 解决面部稳定性（皮肤纹理 + 动态表情渲染）。两项 3DGS 成果入选 **ACM Multimedia 2026**。
  「智引」平台：描述教学意图 + 复刻形象音色 → **分钟级生成**专属 AI 教学智能体。
  爱学大模型把**学习者认知状态、情绪波动、跨课时记忆**作为教学决策输入。
  落地：数字人导师「苏轼」进北京海淀人北实验学校 AI 公开课；WAIC 2026 孔子数字人体验舱。
- **海亮科技**：依托集团 30 余年实体办学经验，选「场景驱动技术」；AI 产品服务全国 **230 余个区县**。
  「星乐读」聚焦**语文/英语早读**痛点，数字人复刻 + 多模态语音评测，支持跟读/齐读/角色扮演，
  实时记录朗读表现 → 个性化学情档案 → 教师分层教学。
- **科大讯飞**：2026-07 发布**超拟人数字人实时生成**技术 —— 从「实时驱动」升级为「实时生成」，
  **仅需一张照片**即可实时生成并自然交互（此前需约 2 小时真人视频采集 + 长周期训练）；
  支持取物/喝水/唱歌/跳舞等复杂动作。已支持 **37 种语言**。
- **世优科技**：高精度建模 + AI 驱动还原面容/眼神/语音语调；陶行知教育思想专属垂直知识库，
  经智能体平台训练后**交互正确率 98%**；**180 余个面部控制点**呈现情绪。以一体机形式部署在
  合川四大教育传承地标。同类模式已复制到乐山郭沫若故居、郑成功诞辰 400 周年等。
- **木愚科技**（方直科技子公司）：AI 数字化课程生成系统，四项核心技术（个性化语音训练与驱动 /
  高自然度数字形象生成与驱动 / AIGC 场景融合 / 专业共建 GPT）；真人超写实数字教师分身，
  输入教案文字即可生成教学视频。**已通过华为昇腾原生技术认证**。
- **蝉镜**：轻量工具，输入文案生成数字人视频，支持 PPT/PDF 转视频。课堂案例：
  西咸新区沣西新城第二学校用其虚拟伙伴「鹮灵」贯穿项目式学习，承担引导者/陪伴者/情境营造者三重角色。

**四条结构性判断**

1. **技术路线分化为「场景深耕」与「通用平台」两条路径。** 与爱为舞、海亮科技走「先找教学切口、
   再反向构建数字人能力」，数字人深度绑定教学流程；科大讯飞从通用平台向教育延伸，技术底座更宽、
   教育针对性较弱。
2. **3DGS 正在降低高拟真数字人的制作门槛。** AnyAvatar 突破专业标定设备依赖 → 教育机构未来可能
   以更低成本获得高拟真数字人。
3. **「分钟级生成」成为标配方向。** 与爱为舞的「智引」、讯飞的「一张照片实时生成」都在压缩制作周期，
   目标是**让教师自主创建**，而非依赖专业技术团队。
4. **轻量工具与深度产品并存。** 蝉镜让无技术背景的教师也能做数字人微课；与爱为舞、海亮则深入教学决策层。
   两者不是替代关系，而是覆盖不同需求层级。

## 3. 操作步骤（MUST）

调研口径是「**只用可查证的公开信息，厂商宣传单独标注**」：

```text
1. 定范围：教育方向数字人（国内厂商）+ 数字人方向通用平台（做技术路线对照）
2. 分层检索：
   - 教育：Khanmigo / Duolingo Max / 洋葱学园智能学伴 / 松鼠Ai(MCM+知识图谱) / 清华 OpenMAIC
   - 数字人：腾讯云数智人 / HeyGen / Synthesia / 九马 / 百度曦灵 / duix
   - 国内教育数字人专项：与爱为舞 / 海亮科技 / 科大讯飞 / 世优科技 / 木愚科技 / 蝉镜
3. 每家用统一字段抽取：核心定位 / 技术路线 / 落地形态 / 可核事实（论文、认证、公开课、部署地点）
4. 交叉验证：论文与认证（ACM MM 2026、昇腾认证）属硬事实；
   「98% 正确率」「230 余区县」类厂商自述标注为宣传口径，不作为对标基线
5. 与自己项目对齐：逐条问「这条能力我们有没有 / 差别在哪 / 要不要补」
```

**沉淀出的对照结论（本项目 vs 赛道）**

| 维度 | 赛道普遍做法 | 本项目现状 |
|---|---|---|
| 数字人形象 | 3DGS 高拟真建模 / 一张照片实时生成 | MuseTalk 口型驱动（真人素材 + 音频驱动） |
| 内容生成 | 分钟级生成、教师自助 | 未做（无可视化编排平台） |
| 教学决策 | 认知状态/情绪/跨课时记忆入决策 | 未做（无学习域后端） |
| 链路形态 | 多为「生成式内容」或「一体机部署」 | **实时交互链路**（ASR→LLM→TTS→口型，流式并行 + VAD 打断） |
| 可量化性 | 少见公开延迟/同步指标 | **逐段延迟预算 + 评估台账**（见 `../eval-history.md`） |

## 4. 难点与解决（HUMAN）

**难点 1：厂商宣传与可核事实混在一起。**
几乎所有报道都会写「分钟级生成」「正确率 98%」「服务 XX 个区县」，但很少给测试条件、样本量或基线。
处理办法：把事实分三档 —— **可核硬事实**（论文入选、技术认证、公开课现场）、**厂商自述**（数字指标）、
**待验证**（规模化成本、长期教学效果）。写进简历或对答时只用第一档，第二档必须挂「据厂商」。

**难点 2：赛道横向对比容易变成罗列，落不到自己身上。**
第一版写完就是一张厂商表，读完不知道自己该做什么。补了「本项目 vs 赛道」对照表之后才有用 ——
它直接回答了面试官最爱追问的那句「**你和他们比，差异在哪**」。

**难点 3：这份调研原本无类型可归。**
项目文档体系是闭集（PRD/DESIGN/ADR/PROGRESS/RETRO + 扩展类），没有「调研报告」这一类。
先想塞进 `docs/_inbox/`，但该目录被 `.gitignore` 忽略、不进 git，推不上云端（本轮的真实需求就是推云端）。
最终判定：它符合 `docs-guide.md` 里 **tech（知识笔记）** 的定位 ——「我掌握了什么，服务未来的我」，
于是按 TECH 模板六段成型：技术要点放厂商与路线，操作步骤放**调研方法**（而非代码步骤），
亮点段锚到我方的真实实现文件。**没有为套模板编造内容**。
